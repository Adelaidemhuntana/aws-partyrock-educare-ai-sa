AWS EduCare Cloud Support Platform

Serverless learner support prototype using S3, API Gateway, Lambda, DynamoDB, CloudWatch and AWS PartyRock.

Learner Support Request

This form represents the S3 hosted frontend. In the cloud version it sends requests to API Gateway and Lambda.

Cloud Architecture

1. Amazon S3
Hosts this static frontend.
2. API Gateway
Provides the HTTPS endpoint.
3. AWS Lambda
Processes the support request.
4. DynamoDB
Stores the learner request and recommendation.
5. CloudWatch
Shows logs and function monitoring.
6. AWS PartyRock
Demonstrates the generative AI learning support layer.
